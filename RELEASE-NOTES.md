# keelrail v0.1.0 — first public release

The open interface for the non-custodial payment rail for AI & agent work.

- **x402 / USDC** payment shape across Base, Arbitrum, Polygon, Optimism (HTTP 402 → pay → credit).
- **Discovery manifest** at `/x402.json` so buying agents auto-find services + prices + pay-to.
- **Endpoint interface:** chat completions, layered agent tasks, defensive audit (authorized), synthetic data, config-fix, timezone.
- **Open interface (MIT); sovereign engine stays private** — open-core by design.

Non-custodial throughout: funds move peer-to-peer, the rail never holds them.
