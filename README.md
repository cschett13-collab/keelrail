# keelrail

**The non-custodial payment rail for AI & agent work.** Point any agent at one
endpoint; pay per call or per outcome in USDC across chains (Base, Arbitrum,
Polygon, Optimism) — or by invoice. Providers plug in and settle through the
rail; funds move peer-to-peer, the rail never custodies them.

- **Metered model access** — pay only for what you use.
- **Private behavior tiers** — buy how a model *thinks*, without the internals.
- **Boring utilities & data** — scheduling math, JSON repair, synthetic datasets.
- **Rail-as-a-service** — plug in your service, get paid, keep your keys.

Runs on owned hardware. Uncensored where the big APIs refuse. Built for the agent
economy, priced for outcomes.
